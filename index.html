Robinhood Trading Agent (MCP)

This site is configured to work with a Robinhood trading agent exposed over MCP at https://agent.robinhood.com/mcp/trading. It lets a connected agent read account/portfolio data and, when explicitly authorized, place trade orders.

Live trading, human-in-the-loop only. No order is ever placed automatically. Every trade action requires the account owner to authenticate with Robinhood directly and explicitly confirm the order before it is sent. This repository does not store Robinhood credentials, API keys, or session tokens.

See docs/robinhood-trading-agent.md for setup and the safety model.
